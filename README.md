# jsheets245.github.io

Modern personal website for a frontend software engineer, designed for GitHub Pages and built with React, TypeScript, and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploying to GitHub Pages

This project is configured for a GitHub Pages deployment with a relative base path. For a user site hosted at `jsheets245.github.io`, the default domain works without any extra path configuration.

```bash
npm run deploy
```

The deploy command runs the production build and publishes the `dist` folder to the GitHub Pages branch.
